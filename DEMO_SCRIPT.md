# Quick Demo Script (about 60–90 seconds)

1. Open StudyPilot AI at `http://127.0.0.1:5000` and sign in.
2. Show the dashboard and say it helps students organize study tasks.
3. Open Upload PDF and demonstrate a sample PDF upload if time allows.
4. Open Study Plan and add a short task.
5. Open Quiz and show a practice quiz result.
6. In a second terminal, run `python mcp_server.py`; show the startup message and explain that the local MCP Streamable HTTP endpoint is `http://127.0.0.1:8001/mcp`. The server exposes `get_study_advice`, `create_quick_quiz`, and `get_study_tip`.
7. Be transparent: `/alexa-demo` is a simulated Alexa-style web experience, not a live Alexa+ integration.

To record on Windows, press `Win + Alt + R` (Xbox Game Bar) if recording is enabled. Otherwise use Windows Snipping Tool screen recording if available.
